**자캐커뮤 및 타임라인식 TRPG 세션을 위하여 개조된 마스토돈 소스입니다.** 약 50명 내외의 작은 규모를 대상으로 개조되었으며, 커뮤 러닝을 위한 각종 편의 기능이 추가되었습니다.

원본 마스토돈은 [공식 저장소](https://github.com/mastodon/mastodon)를 참고하세요. 해당 문서는 마스토돈 순정판에서 추가/수정이 된 부분만 정리하여 명시합니다.

## 외부 공개/글 공개 범위

**로그인하지 않으면 서버 내 글 및 계정 확인이 불가능**합니다. 타 마스토돈 연합과의 연결 또한 불가능하니 참고해주세요.

각 계정의 글 공개 범위는 **전체 공개 / 팔로워 / 개인 멘션**입니다. 개인 멘션은 1:1 DM기능과 유사합니다.

## 글 꾸미기

글씨 꾸밈/강조를 위해 디스코드와 같은 문법이 적용됩니다.

| 이렇게 쓰면 | 이렇게 보입니다 |
|---|---|
| `**굵게**` | **굵게** |
| `*기울임*` | *기울임* |
| `__밑줄__` | 밑줄 |
| `~~취소선~~` | ~~취소선~~ |
| `\|\|스포일러\|\|` | 가려져서 올라가고, 누르면 보입니다 |
| `` `코드` `` | 고정폭 글씨 |

작성창 아래 **글자 서식 버튼**을 누르면 사용 가능한 강조 커맨드가 보입니다. 목록에서 고르면 커서 자리에 기호가 들어가고, 글자를 드래그해 놓고 누르면 그 부분을 감싸줍니다.

## 예약 툿

작성창 아래 시계 모양 버튼을 누르면 시간을 고를 수 있습니다. 예약 시점으로부터 최소 5분 이후로만 예약이 가능합니다. 시간을 정하면 게시 버튼이 "예약"으로 바뀝니다.

예약해 둔 글 리스트는 왼쪽 메뉴의 **예약 메시지**에서 확인합니다. 해당 항목에서 예약글을 취소 및 수정이 가능합니다. 단, 수정 시 첨부한 이미지는 재첨부가 되지 않으니 다시 올려주세요.

퍼블릭이 아닌 답글도 예약이 됩니다. 단, 예약해 둔 사이에 답을 해야 하는 원글이 지워지면 그 예약은 발행되지 않고 사라집니다.

## 계정 전환 설정

트위터 앱이나 웹과 동일하게 계정을 여러 개 등록해두고 바꿔가며 쓸 수 있습니다.

왼쪽 메뉴 **계정 전환** → **기존 계정 추가**로 다른 계정에 로그인해 두면, 그다음부터는 목록에서 누르기만 하면 바로 전환됩니다.

등록 정보는 그 브라우저에만 남습니다. 폰이나 다른 컴퓨터에는 따라가지 않으며, 쿠키를 지우면 전부 로그아웃됩니다.

## 그룹 메시지

다인이 참여 가능한 실시간 DM방입니다. 왼쪽 메뉴의 **그룹 메시지**에서 열립니다.

### 화면 구성

트위터 DM과 같은 방식입니다. 넓은 화면에서는 왼쪽에 참여 중인 방 목록, 오른쪽에 고른 방의 대화가 나란히 열립니다. 화면이 좁거나 모바일이면 목록 → 대화 순서로 한 화면씩 넘어가며, 대화 화면 왼쪽 위 화살표로 목록으로 돌아옵니다.

**방 목록**에는 방 이름과 함께 **마지막으로 오간 메시지와 시간**이 보이고, 최근에 대화가 있었던 방이 위로 올라옵니다. 내가 쓴 메시지에는 앞에 `나:` 가 붙습니다. 위쪽 검색창으로 방 이름을 찾을 수 있고, 오른쪽 위 버튼을 누르면 새 방을 만듭니다.

**대화**는 말풍선으로 표시됩니다.

- 내 메시지는 오른쪽 파란색, 상대 메시지는 왼쪽 회색으로 아바타·이름과 함께 보입니다.
- 같은 사람이 연달아 쓴 메시지는 하나로 묶이고, 묶음 끝에 시간이 붙습니다. 날짜가 바뀌면 구분선이 들어갑니다.
- 새 메시지는 실시간으로 아래에 쌓이고, 위로 올리면 이전 대화를 계속 불러옵니다.
- 첨부한 이미지는 말풍선 안에 붙고, 누르면 크게 볼 수 있습니다.
- 글자 효과(굵게·스포일러 등)는 말풍선 안에서도 그대로 적용됩니다.

**입력창**은 화면 아래에 고정되어 있습니다. `Enter`로 전송, `Shift + Enter`로 줄바꿈이며 글이 길어지면 입력창이 알아서 늘어납니다. 왼쪽 사진 버튼으로 이미지를 최대 4장까지 첨부합니다.

### 방 관리

방은 전부 초대제로, 방을 만든 사람이 멤버를 선택하여 초대합니다. 대화 화면 오른쪽 위 아이콘에서 방장은 **멤버 초대/관리**를, 멤버는 **방 나가기**를 누를 수 있습니다.

방에 쓴 글은 방 안에서만 보이며, 툿 수에 집계되지 않습니다. 글을 눌러도 상세보기로 넘어가지 않으며, 답글이나 부스트는 불가능합니다. 방을 나가도 그동안 쓴 글은 방에 남습니다.

**주의: 방장이 탈퇴 시, 해당 방이 영구히 사라집니다. 모든 멤버가 방에서 나가게 되고 방에 오간 메시지도 전부 삭제됩니다.**

## 답장 안 한 메시지

왼쪽 메뉴의 **답장 안 한 메시지**를 열면 최근에 받은 멘션 100개 중에서 아직 아무 반응도 하지 않은 것만 모아서 보여줍니다.

답멘을 달거나 / 좋아요를 찍거나 / 부스트를 하면 해당 목록에서 제외됩니다.

## 인용

인용 기능이 추가되었습니다. 동일한 서버 내의 툿 링크를 첨부하면 **인용 허용**이 된 게시글에 한해 인용이 가능해집니다.

## 자잘하게 알아둘 것

- 알림 이메일은 디폴트로 전부 꺼져 있습니다. 필요하면 환경설정에서 항목별로 켜주세요.
- 푸시 알림이나 알림 메일 미리보기에는 글자 효과가 적용되지 않고 `**이런**` 기호가 그대로 보입니다.
- 유행이나 프로필 추천 같은 발견하기 기능은 꺼져있습니다. 실제 소스를 수정하여 ON시 이용이 가능합니다.

## 추가된 메뉴 위치

- **서버 설정 → 외관**에서 로고와 배경 이미지를 테마별로 업로드 가능합니다.
- **중재 → 그룹 메시지**에 해당 서버 전체 그룹 메시지들을 확인 가능합니다.
- **중재 → 계정 → 아이디 클릭 → 게시물**을 클릭 시 각 계정의 툿 확인이 가능합니다. DM과 DM 제외가 있으며, 대화 상대 검색 또한 가능합니다.
